# Security Policy

This provider handles SendGrid API keys, subuser passwords, and OAuth client secrets. If you find a security
issue — for example, a case where a sensitive value could leak into Terraform plan output, logs, or state in
an unexpected way — please report it privately rather than opening a public GitHub issue.

Report security issues to Twilio Security through Twilio's standard internal vulnerability reporting process,
or contact the maintainers listed in [CODEOWNERS](.github/CODEOWNERS) directly.

Please do not include real API keys or other live credentials in a report — describe the issue and, if needed,
provide redacted or synthetic reproduction steps.
